# Study Tracker (Android)

1. Create a free account at github.com and make a NEW repository (any name).
2. Upload everything in this folder to it (drag and drop on "uploading an existing file"; make sure the hidden `.github` folder is included).
3. Open the repo > Actions tab > "Build APK" > Run workflow (it also runs automatically on upload). Wait ~5 minutes.
4. Open the finished run > Artifacts > download "study-tracker-apk", unzip it, and send app-debug.apk to your phone.
5. On the phone, open the APK, allow "install from unknown sources" when asked, install.
6. On first rest, tap Allow for notifications.
